# Asset Credits

The default game requires no downloaded art. All floor tiles, ward textures, beds, patient/nurse markers, reception, and ambulance are generated with Phaser Graphics in `frontend/src/game/AssetProvider.ts`.

## Optional Overrides

`frontend/public/assets/manifest.json` can be populated with explicitly licensed CC0 or compatible texture-pack overrides. Any future third-party asset must include:

- creator and source URL,
- exact license name/version,
- usage files,
- modification notes,
- attribution required in this document.

No commercial hospital game assets are copied or redistributed. Fonts are loaded through Google Fonts: Baloo 2, Rubik, Inter, and JetBrains Mono; license information is governed by the upstream font licenses and the linked service’s terms.
